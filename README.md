# Login-system
🔐 Simple Python Login System

This is a basic login authentication program written in Python. It checks whether the entered email and password match the stored credentials and displays appropriate messages.

🚀 Features
User login using email and password
Basic authentication using conditions
Displays clear messages for different cases
Beginner-friendly code
💻 How It Works
User enters email
User enters password
Program compares input with stored credentials
Displays result:
✅ Login Successful
❌ Incorrect Password
❌ Incorrect Credentials
